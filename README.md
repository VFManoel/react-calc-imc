
# BMI Calculator

A BMI (Body Mass Index) calculator built with React and TypeScript. This application allows users to calculate their BMI by entering height and weight values and provides the corresponding BMI category.

## Features

- Calculate BMI using height and weight
- Display BMI result instantly
- Show BMI category (Underweight, Normal, Overweight, etc.)
- Responsive interface

## Technologies Used

- React
- TypeScript
- CSS
